# Arithmetic progressions in sumsets
Consider a finite set of integers $A$. Denote by $n A$ the $n$-th sumset, i.e. the set of all possible sums of $n$ elements from $A$. Let $\ell (X)$ be the number of elements in the largest arithmetic progression in $X$ minus one. Is it true that the sequence
$$ c_n = \frac{\ell(n A)}{n} $$
is non-decreasing?

Note that it is easy to show that
\[ c_{k n} \geq c_{n}, \]
since we can take an arithmetic progression $a, ..., a + m d$ in $n A$ and obtain an arithmetic progression $k a, ..., k a + k m d$ in $k n A$.
